UCAS Application Guide

英国本科申请指南

概述

UCAS（Universities and Colleges Admissions Service）是英国大学和学院的统一招生服务机构，负责处理英国本土及国际学生的本科入学申请。几乎所有英国大学的本科课程都通过UCAS系统进行申请。

适用人群：计划申请英国本科（Undergraduate）课程的学生，包括英国本土学生、欧盟学生及国际学生。

关键时间节点

9月1日 — UCAS申请系统正式开放，可以开始填写并提交申请。
10月15日 — 牛津大学、剑桥大学以及医学、兽医、牙科等课程的申请截止日期。
1月25日 — 大部分英国大学本科课程的平等考虑截止日期（Equal Consideration Deadline）。
6月30日 — 常规申请通道关闭，此后提交的申请自动进入补录（Clearing）阶段。

申请步骤

  1. 注册UCAS账号 — 访问 ucas.com 创建个人账号，获取唯一的UCAS ID。
  2. 选择5个志愿 — 最多可申请5门课程，可以是同一所大学不同专业，也可以是不同大学的相同或不同专业。牛津和剑桥只能二选一。
  3. 填写个人陈述（Personal Statement） — 撰写一篇不超过4000字符的个人陈述，展示学术兴趣与动机。
  4. 推荐信 — 由学校老师、导师或辅导员提供一封学术推荐信。
  5. 提交申请 — 确认所有信息无误后支付申请费并正式提交。

Personal Statement 要求

  • 字数限制：4000字符（含空格）或 47行，以先到者为准。
  • 内容应以学术兴趣为主，占全文的70%以上。
  • 重点阐述为什么想学习该专业、相关的学习经历、课外阅读及研究。
  • 不能提及具体学校名称 — 因为同一份PS会发送给所有5个志愿。
  • 避免拼写和语法错误，保持真实、简洁、有说服力。

牛津剑桥特殊要求

申请牛津大学或剑桥大学除了常规的UCAS申请外，还有额外要求：

  • 入学考试 — 根据专业不同需参加特定考试，如TSA（思维能力测试）、MAT（数学入学测试）、PAT（物理能力测试）、LNAT（法律）、BMAT（医学）等。
  • 面试 — 牛剑的面试以学术讨论为主，通常在12月进行，由学院导师直接考核学生的思维能力和学术潜力。
  • 更早截止 — 牛剑及医学类专业的申请截止日期为10月15日，比其他学校早近3个月。

申请费用

  • £22.50 — 申请单个课程。
  • £27.00 — 申请多个课程（2-5个志愿）。

语言要求

英国大学本科通常要求国际学生提供雅思（IELTS）成绩，一般要求为：

总分 6.5 - 7.5，单项不低于 6.0 - 7.0（具体要求因学校和专业而异）。

部分顶尖大学或语言要求高的专业（如法律、英语文学、医学）通常要求总分7.0-7.5。建议在申请前确认目标院校的具体要求。

Official Resources 官方资源

所有备考以官方资源为基准，第三方教材用于补充练习。

  • Bluebook App
    College Board 官方机考模拟软件，含 4-6 套完整自适应模考，必须熟习界面与计时。
  • Khan Academy Official SAT Practice
    与 College Board 合作的免费在线题库，可绑定 PSAT/SAT 成绩生成个性化练习。
  • Question Bank (College Board)
    官方按技能点分类的题库，用于定向突破弱项。
  • SAT Student Guide
    官方发布的年度考生手册，含考试规则、计分方式与样题。

Prep Timeline 备考节奏

建议 12-16 周完成一个完整备考周期，可按下面四阶段推进。

Phase 1 · Diagnostic (Week 1-2)
用 Bluebook 第 1 套模考建立基线分数，按 RW/Math 模块分析错题类型，定位薄弱技能点。
Phase 2 · Skill Building (Week 3-8)
按技能点专项练习（Khan Academy + Question Bank），每周完成 1 套完整模考，错题入错题本。
Phase 3 · Practice Tests (Week 9-12)
每周 1-2 套 Bluebook 模考，严格按考试时段（上午）进行，训练耐力与时间分配。
Phase 4 · Final Tune-up (Week 13-16)
回归错题本，针对性复习，考前 1 周停止做新题，保持手感与作息。

Module Strategy 分模块策略

  • Reading & Writing
    机考 RW 改为短篇章单题，重点是题干-文本-选项三向匹配。训练先读题干再扫文本的检索式阅读，避免逐字精读。
  • Math (No Calculator & Calculator)
    机考数学全程允许使用计算器，自带 Desmos 风格图形计算器。重点训练用计算器解方程、画图求交点，节省时间。
  • Adaptive Module Strategy
    第一模块决定第二模块难度。前 8 题权重更高，宁可放慢确保正确率，不要在难题上耗时过多导致后段简单题失分。

Error Log Practice 错题本规范

错题本质量直接决定提分上限，建议每道错题至少记录以下四项。

Question (题目)抄录或截图，标注来源（如 Bluebook Test 3 Q12）
Error Type (错误类型)知识盲区 / 审题失误 / 计算失误 / 时间不足
Correct Approach (正确思路)用一句话写下"应该怎么想"
Takeaway (要点)下次遇到同类题先做什么动作（如先标关键词、先画图）

Test Day Checklist 考试当日清单

  • Device
    充满电的笔记本或 iPad，安装好 Bluebook 并完成 Setup。
  • ID
    护照或政府签发带照片证件，姓名与准考证一致。
  • Admission Ticket
    打印纸质准考证，提前核对考点地址。
  • Calculator
    自带计算器（可选），机考内置 Desmos 已够用。
  • Snack & Water
    休息时补充能量，避免高糖导致犯困。
  • Arrival
    提前 30 分钟到达考点，留出签到时间。

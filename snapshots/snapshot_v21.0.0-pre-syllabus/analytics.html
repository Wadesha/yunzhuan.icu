第三方统计 SDK Third-party

Google Analytics 4 (gtag.js)

在 <head> 顶部插入：

<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>

获取 Measurement ID：analytics.google.com

百度统计 (Baidu Tongji)

在 <body> 顶部插入：

<script>
var _hmt = _hmt || [];
(function() {
  var hm = document.createElement("script");
  hm.src = "https://hm.baidu.com/hm.js?xxxxxxxxxxxxxxxxxxxxxxxxxx";
  var s = document.getElementsByTagName("script")[0];
  s.parentNode.insertBefore(hm, s);
})();
</script>

获取站点 ID：tongji.baidu.com

自定义事件追踪 Custom API

暴露 window.Analytics.track(event, props)，自动转发到 GA4 / 百度 / 控制台。

// 引入 js/analytics.js（v58 新增）后
window.Analytics.track('practice_start', { subject: 'sat', source: 'homepage' });
window.Analytics.track('mock_test_complete', { subject: 'act', score: 32, accuracy: 88.5 });
window.Analytics.track('pwa_installed', { source: 'shortcut_mock' });

事件类型约定

事件名触发时机
page_view自动
practice_start用户进入刷题页
answer_submit提交答案
mock_test_complete模拟考完成
dashboard_open打开仪表盘
pwa_install_prompt触发 PWA 安装
pwa_installedPWA 安装完成
locale_change切换语言
share_target_receivedPWA 接收分享题库

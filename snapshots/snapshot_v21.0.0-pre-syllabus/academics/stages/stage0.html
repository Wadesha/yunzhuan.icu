Stage 0 · 探索期

Grade 8-9 · Year 9 · 还没开始国际课程，正在选路径

本阶段重点

  1. 了解三条主流路径（英系/IB/美系）的区别和适合人群：英系 A-Level 重学科深度、IB 重全面发展、美系 AP 重 GPA 与课外活动，不同路径对应不同目标国家和能力模型。
  2. 评估自己的学术兴趣和优势学科：回顾过去两年各科成绩与课堂体验，找出真正喜欢且擅长的方向，为后续选课提供依据。
  3. 了解目标国家的大学要求：美国看全面发展（GPA + 标化 + 活动 + 文书），英国看学科深度（预估成绩 + 笔试面试），不同国家准备重心完全不同。
  4. 确定初中课程方向（IGCSE / 美高 9-10 / Pre-IB）：初中课程决定高中可选路径，例如计划 IB 则优先 Pre-IB 或 IGCSE，计划 A-Level 则选 IGCSE。
  5. 开始英语能力培养（阅读习惯 > 刷题）：此阶段不应急于刷标化题，而应通过原版阅读、词汇积累建立长期英语能力，为后续 IELTS/TOEFL/SAT 打底。

常见误区

  • 盲目跟风选 IB：不考虑自己能否承受 IB 的 workload（6 门学科 + TOK/EE/CAS），结果高中疲于奔命、各科都不突出。
  • 过早开始标化刷题：这个阶段应该培养能力而非应试，过早刷 SAT/IELTS 题既低效又消耗兴趣。
  • 忽视英语阅读习惯的养成：等到 11 年级才发现阅读量不够、词汇薄弱，再补为时已晚。

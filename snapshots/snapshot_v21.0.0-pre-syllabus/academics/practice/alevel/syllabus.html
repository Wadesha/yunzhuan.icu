Mathematics（Edexcel 结构通用）

AS 纯数 P1 (Paper 1)

  • 1. 代数：指数与根式运算、多项式除法、因式定理与余数定理
  • 2. 二次函数：判别式 Δ=b²-4ac、根与系数关系（韦达定理）、配方法、二次不等式
  • 3. 不等式：线性不等式、含绝对值不等式 |ax+b|、联立不等式组
  • 4. 坐标几何：直线方程（点斜/两点/截距）、两条直线垂直与平行、圆的方程 (x-a)²+(y-b)²=r²、切线方程
  • 5. 三角比：sin/cos/tan 定义、180-θ/90-θ 补角关系、特殊角(30/45/60)、正弦定理/余弦定理、三角形面积
  • 6. 微分：幂函数微分 d/dx(xⁿ)=nxⁿ⁻¹、切线与法线方程、单调性(递增递减)、驻点与极值（极大/极小）、二阶导数判别
  • 7. 积分：逆幂积分 ∫xⁿdx=xⁿ⁺¹/(n+1)、定积分计算、曲线与x轴围成面积、两条曲线围成面积
对应Q：Q1‧Q11‧Q32‧Q51‧Q52‧Q53
Topic 锚点：M-P1-11(3) · M-P1-12(1) · M-P1-16(1) · M-P1-17(1)

AS 纯数 P2 (Paper 2)

  • 1. 指数与对数：运算法则 aᵐ·aⁿ=aᵐ⁺ⁿ、对数变换 logₐb、自然对数 ln x 与 eˣ、指数方程对数方程、指数增长衰减模型
  • 2. 二项式展开：(1+x)ⁿ 展开式、通项 C(n,r)xʳ、近似值计算、n 为正整数情形
  • 3. 三角恒等式：sin²θ+cos²θ=1、tanθ=sinθ/cosθ、二倍角公式 sin2θ/cos2θ、辅助角公式 Rsin(x+α)/Rcos(x-α)、三角方程求解
  • 4. 微分2：链式法则 dy/dx=dy/du·du/dx、乘积法则 d(uv)/dx=u'v+uv'、商的法则 d(u/v)/dx=(u'v-uv')/v²
  • 5. 积分2：简单换元积分、∫(1/x)dx=ln|x|、∫eˣdx=eˣ、∫sinx/cosx dx、简单有理函数积分
  • 6. 数值法：迭代法 xₙ₊₁=f(xₙ)求根、梯形法则近似定积分、误差判断

A2 纯数 P3 (Paper 3)

  • 2. 函数：定义域与值域、反函数 f⁻¹(x)、复合函数 fg(x)、函数图像变换（平移/伸缩/反射/模）

力学 M1 + M2（可选路径）

  • M1 力学 1：
    • 运动学：匀变速直线运动 suvat 五公式、竖直上抛与自由落体、二维相对运动基础
    • 力与平衡：牛顿三定律、F=ma、重力/支持力/摩擦力 F=μR、力的分量分解、共点力平衡
    • 动量与冲量：冲量 I=Ft、动量守恒 m₁u₁+m₂u₂=m₁v₁+m₂v₂、碰撞方向
    • 连接体：滑轮/斜面/绳子张力、整体法与隔离法
    • 力矩：力矩 τ=F×d、杠杆平衡、非共点力力矩条件
  • M2 力学 2：
    • 抛体运动：二维抛体轨迹方程、最大高度/射程、落地速度

    • 碰撞与恢复系数：牛顿恢复定律 e=(v₂-v₁)/(u₁-u₂)、动能损失、斜碰基础
    • 刚体转动惯量基础：I=∑mr²、平行轴与垂直轴定理、转动动能

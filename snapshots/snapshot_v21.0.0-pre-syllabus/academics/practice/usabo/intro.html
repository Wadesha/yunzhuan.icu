USABO Overview v29

USA Biology Olympiad · 生物奥林匹克竞赛体系

USABO 体系：USA Biology Olympiad（美国生物奥林匹克）由美国生物教师协会（NABT）主办，分为初赛（Open Exam）和复赛（Semi-final Exam），最终选拔出代表美国参加 IBO（国际生物奥林匹克）的国家队。

学习路径

Stage 1：AP Biology 基础 — 掌握细胞、遗传、进化核心概念

Stage 2：USABO Open Exam — 速度训练与广度覆盖（50题/50min）

Stage 3：USABO Semi-final — 深入分子生物与生理学细节

Stage 4：National/IBO — 实验技能与综合分析能力

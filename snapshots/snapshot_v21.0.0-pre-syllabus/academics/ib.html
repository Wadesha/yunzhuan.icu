IB Diploma Programme

International Baccalaureate · 国际文凭课程 · 两年制（11-12 年级）

Overview

IB Diploma Programme（IBDP）是由国际文凭组织（IBO）开设的两年制高中课程，面向 16-19 岁学生。全球 150+ 个国家、5000+ 所学校开设。IB 以"全人教育"著称，强调学术深度、批判性思维和社会责任。

课程结构（6 大学科组 + 3 核心）

学科组说明常见科目
Group 1语言与文学（Studies in Language and Literature）中文 A 文学 / 英文 A 文学 / 英文 A 语言与文学
Group 2语言习得（Language Acquisition）英文 B / 中文 B / 法语 B / 西班牙语 B
Group 3个人与社会（Individuals and Societies）经济 / 历史 / 地理 / 心理 / 商管
Group 4科学（Sciences）物理 / 化学 / 生物 / 计算机科学 / 环境系统
Group 5数学（Mathematics）数学 AA HL / 数学 AA SL / 数学 AI HL / 数学 AI SL
Group 6艺术（The Arts）— 可选，可用 Group 3/4 替代视觉艺术 / 音乐 / 戏剧 / 电影

3 大核心课程

  • TOK（Theory of Knowledge）：认识论课程，探讨"我们如何知道我们所知道的"。需完成 1600 字论文 + 口头展示。满分 2 分。
  • EE（Extended Essay）：4000 字独立研究论文，选题自由。满分 2 分。
  • CAS（Creativity, Activity, Service）：创意、运动、服务三项课外活动，需完成 150 小时并记录反思。不计分但必修。

评分体系

  • 每门学科：1-7 分，6 门学科最高 42 分
  • TOK + EE：最高 3 分（核心分数）
  • 总分：45 分满分（42 + 3）
  • 24 分为及格线，获得 IB Diploma

IB 与留学申请

目标国家IB 认可度关键要求
美国极高，Top 20 普遍认可HL 课程数量、总分、EE/TOK 成绩。IB 学生常被视为"学术准备最充分"
英国极高，G5 直接按 HL 成绩录取通常要求 HL 666 或 HL 776，部分专业要求特定 HL 科目
加拿大高，可换学分多数大学接受 IB 直接申请，部分可换大一学分
澳洲高，可换学分Group of Eight 普遍接受，高分可换学分或免预科
香港高港大/港中文/港科大均接受 IB，通常要求 36+
新加坡高NUS/NTU 接受 IB，通常要求 38+

IB 适合什么样的学生

  • 适合：学术兴趣广泛、自我驱动力强、时间管理能力强、希望接受"全人教育"、目标英美顶尖大学
  • 不适合：偏科严重、希望集中精力在 2-3 门学科、无法承受高强度 workload（IB 被广泛认为是高中课程体系中工作量最大的）

时间线（两年制）

  • DP1（11 年级）：6 门学科同步推进 + TOK 课程 + CAS 活动启动 + EE 选题
  • DP2（12 年级）：学科 IA（内部评估）提交 + EE 终稿 + TOK 论文 + 5 月全球统考
  • 7 月初：成绩放榜（IB Results Day）

申请策略要点

  • 美国：强调"全面发展"，HL 选 3-4 门，EE 选题体现学术兴趣，CAS 活动写进文书
  • 英国：强调"学科深度"，HL 必须与申请专业高度相关，EE 建议与申请专业一致
  • 预估分（Predicted Grades）：由学校老师在 DP2 上学期给出，直接决定大学录取条件

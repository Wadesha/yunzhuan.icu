A-Level Computer Science (AQA)

A-Level 计算机科学（AQA）

AQA 7517

Course Overview 课程介绍

AQA A-Level 计算机科学，线性结构，编程 + 理论 + 项目，含上机考试与编程 NEA。

A-Level Computer Science (AQA 7517) is a linear qualification combining computational thinking, programming, computer systems theory and an independent Non-Exam Assessment (NEA) programming project, examined by two terminal papers at the end of two years plus a portfolio-based NEA. The course covers programming paradigms, data structures, algorithms, computer architecture, networking, databases, Big Data and functional programming. It is a core subject for computer science, software engineering, AI, data science and games development applicants.

AS / Year 1 Syllabus AS 阶段章节

  • AS1. Fundamentals of programming
    Programming paradigms (imperative, object-oriented), data types, variables, sequences/selection/iteration, subroutines, parameters, recursion, exception handling, object-oriented concepts (classes, objects, inheritance, polymorphism)
  • AS2. Fundamentals of data structures
    Arrays (1D and 2D), lists, tuples, records, stacks, queues, linked lists, graphs, trees, hash tables, dictionaries, choosing appropriate data structures
  • AS3. Fundamentals of algorithms
    Sorting (bubble, merge, quick), searching (linear, binary), path finding (Dijkstra, A*), time and space complexity, Big-O notation, recursion
  • AS4. Theory of computation
    Abstraction and automation, finite state machines, regular languages, Turing machines, computability and the halting problem
  • AS5. Fundamentals of data representation
    Number systems (binary, hex), binary arithmetic, character sets (ASCII, Unicode), images, sound, data compression (lossless, lossy), encryption
  • AS6. Fundamentals of computer systems
    Hardware and software, classification of programming languages, generations of languages, systems software, operating systems, types of operating system, role of an operating system
  • AS7. Fundamentals of computer organisation and architecture
    Internal components of a computer, the processor (CPU), processor instruction set, assembly language, Boolean algebra, logic gates, logic circuits
  • AS8. Consequences of uses of computing
    Individual, moral, social, cultural and legal issues, privacy, legislation (Data Protection, Computer Misuse, Copyright), professional bodies
  • AS9. Fundamentals of communication and networking
    Communication methods, networking (LAN, WAN, topologies, client-server and peer-to-peer), TCP/IP protocol stack, protocols, network security and threats
  • AS10. Systematic approach to problem solving
    Analysis, design, implementation, testing, evaluation and maintenance; computational thinking, decomposition, pattern recognition, abstraction

A2 / Year 2 Syllabus A2 阶段章节

  • A211. Fundamentals of databases
    Relational database model, normalisation (1NF, 2NF, 3NF), SQL (DDL, DML), entity-relationship diagrams, transaction processing, ACID
  • A212. Big Data
    Characteristics of Big Data (volume, velocity, variety), distributed processing (MapReduce, Hadoop), NoSQL databases, data mining, ethical and privacy considerations
  • A213. Fundamentals of functional programming
    Functional programming paradigm, function types, map and filter, list processing, first-class functions, function composition, lazy evaluation, Haskell or equivalent
  • A214. Systematic approach to problem solving (advanced)
    Computational methods, algorithms, heuristics, performance modelling, limitations of computational methods
  • A215. NEA: Programming project
    Independent project: analysis of a real problem, design, technical solution developed in a suitable programming language, testing, evaluation; documented portfolio submitted to AQA

Suitable Majors & Pathway 适用专业与衔接

CS、软件工程、AI、数据科学、游戏开发等方向核心科目，含编程项目 NEA。

A-Level Computer Science (AQA) is a core subject for computer science, software engineering, artificial intelligence, data science, cybersecurity, games development, electronics, and computational finance. The linear terminal exams combined with a substantial programming project reward algorithmic thinking, structured problem decomposition and disciplined software engineering, providing a strong foundation for university algorithms and data structures, computer architecture, databases, machine learning and software engineering modules. Often paired with Mathematics and Further Mathematics for top-tier CS applicants.

AP Computer Science (CSA & CSP)

AP 计算机（CSA 与 CSP）

College Board · Advanced Placement

Course Overview 课程介绍

AP 计算机分 CSA（Java）与 CSP（计算思维）两门，4 分以上可换学分。

AP Computer Science, administered by the College Board, comprises two independent exams: AP Computer Science A (Java-based programming and OOP) and AP Computer Science Principles (computational thinking and broad impacts, with a Create performance task). CSA emphasizes Java and algorithms; CSP covers data, algorithms, networks and the societal impact of computing.

Key Facts 基本信息

Administrator (主办方)College Board
Duration (学制)1 year per exam (two independent exams)
Scoring (评分)1 – 5 (5 is the highest)
Programming language (编程语言)CSA: Java; CSP: teacher-selected language
Exam structure (考试结构)CSA: MCQ + FRQ, 50% each; CSP: performance task + MCQ
Lab (实验)CSP includes a Create task; CSA includes in-course programming practice

Sub-Exam: CSA (Java) AP Computer Science A 章节

CSA 基于 Java，含基本类型、对象、控制流、数组、继承与递归共 10 单元。

  • CSAUnit 1. Primitive Types
    int, double, boolean; arithmetic operations and expressions
  • CSAUnit 2. Using Objects
    Classes and objects; String; Math; method calls
  • CSAUnit 3. Boolean Expressions and if Statements
    Relational and logical operators; conditional branching
  • CSAUnit 4. Iteration
    while and for loops; loop control and nesting
  • CSAUnit 5. Writing Classes
    Instance variables and methods; constructors; access modifiers; static members
  • CSAUnit 6. Arrays
    1D array creation and traversal; enhanced for loop; algorithm applications
  • CSAUnit 7. ArrayList
    Dynamic arrays; generics; add, remove, set, get and traversal
  • CSAUnit 8. 2D Arrays
    Matrix representation; row-column traversal and algorithms
  • CSAUnit 9. Inheritance
    Subclasses and superclasses; method overriding; polymorphism; super; Object class
  • CSAUnit 10. Recursion
    Recursive thinking; base cases and recursive calls; classic recursion problems

Sub-Exam: CSP AP Computer Science Principles 章节

CSP 含创造性开发、数据、算法与编程、系统网络与计算影响共 5 单元。

  • CSPUnit 1. Creative Development
    Software development life cycle; team collaboration; iterative design
  • CSPUnit 2. Data
    Binary and data representation; data processing and visualization; big data and privacy
  • CSPUnit 3. Algorithms and Programming
    Variables and assignment; control structures; procedures and modularity; algorithm efficiency
  • CSPUnit 4. Computer Systems and Networks
    Hardware and software; the Internet and protocols; data transmission and redundancy
  • CSPUnit 5. Impact of Computing
    Society and ethics; global interconnection; law and the digital divide

Exam Structure 考试结构

CSA · Section IMCQ · 40 questions · 70 min · 50%
CSA · Section IIFRQ · 4 questions · 90 min · 50% (Methods and Control Structures, Class, Array/ArrayList, 2D Array)
CSP · Create Performance TaskProgramming performance task · code + written response · 30%
CSP · End-of-Course ExamMCQ · 70 questions · 120 min · 70%

Credit Transfer 学分转换与衔接

CSA 4/5 常换算大学编程入门，CSP 多作通识选修，CS 专业常以 CSA 免修。

Both AP Computer Science exams use a 1–5 scale; most US colleges grant credit for 4 or 5. CSA typically maps to an introductory programming course (e.g., CS 101 in Java), while CSP may map to a general computing elective rather than a core CS course. CS majors often accept CSA as a prerequisite waiver. Policies vary by institution.

IB Computer Science

IB 计算机

IB Diploma · Computer Science HL/SL

Course Overview 课程介绍

IB 计算机分 HL/SL，SL 学 4 个核心主题 + 1 个 Option，HL 加抽象数据结构、资源管理、控制及年度 Case Study。

IB Computer Science is a two-year secondary CS course offered by IBO, available at both Higher Level (HL) and Standard Level (SL). SL covers four core topics — system fundamentals, computer organization, networks, computational thinking and programming — plus one Option from databases, modelling and simulation, web science, or object-oriented programming. HL extends SL with abstract data structures, resource management, control, plus an annually released case study. The course emphasizes computational thinking, abstraction, and implementation — a key subject for CS, software engineering, AI, and data science applicants.

SL Syllabus SL 阶段章节

  • SL1. System fundamentals
    System fundamentals / system planning and design / system components / system development life cycle / system maintenance and disposal
  • SL2. Computer organization
    Computer organization / CPU / binary and hexadecimal / memory and storage / input-output devices / operating systems
  • SL3. Networks
    Networks / network fundamentals / protocols / data transmission / the internet / network security basics
  • SL4. Computational thinking, problem-solving and programming
    Computational thinking and programming / algorithm design / pseudocode / flowcharts / Java/Python programming / debugging
  • SL5. Option (choose 1 of 4)
    Options: Databases / Modelling and simulation / Web science / Object-oriented programming

HL Additional Topics HL 额外章节

  • HL6. Abstract data structures
    Abstract data structures / static and dynamic structures / stacks, queues, linked lists / trees, graphs / hash tables
  • HL7. Resource management
    Resource management / processor resources / memory management / system resources / network resources / energy and environmental impact
  • HL8. Control
    Control / automation / robotics / autonomous systems / control system design
  • HL9. Case study (annual release)
    HL case study / IBO releases a themed case each year (e.g., AI, blockchain, cybersecurity); candidates must know related technical, ethical and social issues
  • HL10. OOP in depth (if OOP chosen)
    If Option is OOP, HL deepens: classes, inheritance, polymorphism, encapsulation, introduction to design patterns
  • HL11. Algorithm efficiency and complexity
    HL algorithm analysis / time and space complexity / Big-O notation / sorting and searching algorithm comparison

Internal Assessment 内部评估 IA

IB 计算机 IA 是独立完成的计算解决方案项目，为真实客户解决实际问题，约 2,000 字文档，占 SL/HL 各 30%。

The IB Computer Science IA is an individual computational solution worth 30% of the final grade for both SL and HL. Students solve a real client's problem through a full system development cycle: analysis, design, development, testing, evaluation, with about 2,000 words of documentation plus code and screenshots. SL requires one core solution; HL must additionally demonstrate advanced use of abstract data structures, algorithms, or HL extension topics.

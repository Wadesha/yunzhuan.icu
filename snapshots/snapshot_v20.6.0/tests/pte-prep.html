Prep Timeline 备考节奏

建议 8-12 周完成一个完整备考周期，可按下面四阶段推进。

Phase 1 · Diagnostic (Week 1)
用官方 Scored Practice Test 模考建立基线分数，按 Speaking/Writing/Reading/Listening 分析弱项题型。
Phase 2 · Skill Building (Week 2-6)
按题型专项训练，重点攻克高分值题型（RA/DI/RL/SWT/WE）；积累学术词汇和听力精听。
Phase 3 · Practice Tests (Week 7-10)
每周 1-2 套官方模考，严格按考试时段进行；用模板训练口语流利度和写作打字速度。
Phase 4 · Final Tune-up (Week 11-12)
回归机经高频题和错题本；口语模板熟练到本能反应；考前 1 天休息调整状态。

Key Task Strategies 高分值题型策略

  • Read Aloud (RA) - 朗读
    看短文 30-40 秒后朗读 30-40 秒。重点是流利度（不卡顿、不回读）和发音清晰，语速适中。遇到生词直接跳，不要停顿。
  • Describe Image (DI) - 描述图片
    看图表 25 秒后说 40 秒。模板化输出：标题 → 起点 → 最高点 → 最低点 → 趋势 → 结尾。流利度 > 内容完整度。
  • Re-tell Lecture (RL) - 复述讲座
    听讲座 60-90 秒后说 40 秒。笔记记关键词和逻辑：主题 → 要点 1 → 要点 2 → 结论。用模板串联，保证流利。
  • Summarize Written Text (SWT) - 总结短文
    读 300 词文章后用 1 句话总结（5-75 词）。找主题句 + 核心论点，用 and / which / that 等连接成复合句。
  • Write Essay (WE) - 大作文
    20 分钟写 200-300 词议论文。四段式：引言 → 论点 1 → 论点 2 → 结论。准备 5-8 个通用模板，打字速度要快。

Error Log Practice 错题本规范

错题本质量直接决定提分上限，建议每道错题至少记录以下四项。

Question (题目)抄录或截图，标注来源（如 Official Test 2 S1 Q12）
Error Type (错误类型)词汇不认识 / 语法错误 / 发音不准 / 听力漏听 / 时间不足
Correct Approach (正确思路)用一句话写下"应该怎么想"
Takeaway (要点)下次遇到同类题先做什么动作（如先标关键词、先看图表）

Test Day Checklist 考试当日清单

  • ID
    护照原件，姓名与准考证一致，是 PTE 唯一接受的身份证件。
  • Admission Ticket
    提前打印准考证，或存在手机里备查。
  • Headset & Mic Check
    进入考场后按监考指导测试耳机和麦克风，确保录音清晰。
  • Water & Snack
    休息时补充能量，避免高糖导致犯困。
  • Arrival
    提前 30 分钟到达考点，留出签到和安检时间。

Prep Timeline 备考节奏

建议 12-16 周完成一个完整备考周期，可按下面四阶段推进。

Phase 1 · Diagnostic (Week 1-2)
用 Cambridge IELTS 19 第 1 套模考建立基线分数，按四模块分析弱项；确认 Academic 还是 General Training。
Phase 2 · Skill Building (Week 3-8)
按模块专项练习，每天 30 分钟听力 + 30 分钟阅读；积累高频话题词汇与同义替换。
Phase 3 · Practice Tests (Week 9-12)
每周 1-2 套 Cambridge 真题模考，严格按考试时段进行；Writing 用考官评分标准对照，Speaking 录音回放自评。
Phase 4 · Final Tune-up (Week 13-16)
回归错题本与高频话题卡；Writing Task 1 与 Task 2 训练模板熟练度；考前 1 周保持每日 1 套听力。

Module Strategy 分模块策略

  • Listening (30 min + 10 min transfer, 40 Q)
    4 段听力：2 段日常对话 + 2 段学术讲座。重点训练预读题目、关键词定位与拼写准确（纸笔考试需填答题卡）。
  • Reading (60 min, 40 Q)
    3 篇文章，约 2150-2750 词。题型含 T/F/NG、匹配、填空、选择题、Heading。重点训练 T/F/NG 区分 Not Given 与 False，避免主观推断。
  • Writing (60 min, 2 tasks)
    Task 1（20 min，~150 词）：描述图表（线图、柱图、饼图、表格、流程图、地图）。Task 2（40 min，~250 词）：议论文。重点训练 Task 1 数据对比与 Task 2 论证结构。
  • Speaking (11-14 min, 3 parts)
    Part 1（4-5 min）：日常问答。Part 2（3-4 min）：话题卡 1 分钟准备 + 2 分钟独白。Part 3（4-5 min）：基于 Part 2 的深度讨论。重点训练话题卡结构与 Part 3 抽象表达。

Error Log Practice 错题本规范

错题本质量直接决定提分上限，建议每道错题至少记录以下四项。

Question (题目)抄录或截图，标注来源（如 Cambridge 18 Test 3 Q12）
Error Type (错误类型)知识盲区 / 审题失误 / 听力漏听 / 时间不足
Correct Approach (正确思路)用一句话写下"应该怎么想"
Takeaway (要点)下次遇到同类题先做什么动作（如先标关键词、先看图表）

Test Day Checklist 考试当日清单

  • Device / Materials
    机考：充满电的笔记本或考场电脑；纸笔考：2B 铅笔、橡皮、身份证件。
  • ID
    护照或政府签发带照片证件，姓名与准考证一致。
  • Admission Ticket
    打印纸质准考证，提前核对考点地址。
  • Water & Snack
    休息时补充能量，避免高糖导致犯困。
  • Arrival
    提前 30 分钟到达考点，留出签到时间。

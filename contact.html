How to Request Features 如何提需求

如果你希望我们增加新功能、新页面或新内容，可以按照以下方式提出：

  • 1 GitHub Issues：在 仓库 Issues 中创建一条，详细描述你的需求。
  • 2 邮件或表单：发送邮件或填写上方表单，我们会定期整理和评估。
  • 3 Giscus 留言：在页面底部评论区留言讨论，适合小建议和交流。

Contributing 参与开发

欢迎参与网站建设！以下是一些参与方式：

  • 代码 Fork 仓库，修改后提交 Pull Request。
  • 内容 补充学科内容、学校信息、考试资料等，提交 PR 或发邮件。
  • 翻译 帮助完善中英文双语内容，确保表述准确地道。
  • 反馈 发现 Bug 或有好点子，通过 Issues 告诉我们。

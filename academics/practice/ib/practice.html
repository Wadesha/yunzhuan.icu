Q1 · IB Math AA HL · Calculus · Medium

Find the maximum value of f(x) = x³ - 6x² + 9x + 2 on the interval [0, 4].

  • A) 6
  • B) 2
  • C) 4
  • D) 9
Answer: A) 6. f'(x) = 3x² - 12x + 9 = 0 → x=1 or x=3. f(1)=6, f(3)=2, f(0)=2, f(4)=6. Maximum is 6 at x=1.
Q4 · IB Math AA HL · Algebra · Medium

Given log₂(x) + log₂(x-2) = 3, find x.

  • A) 4
  • B) -2
  • C) 4 or -2
  • D) 8
Answer: A) 4. log₂(x(x-2))=3, x(x-2)=8, x²-2x-8=0, (x-4)(x+2)=0, x=4 (x=-2 rejected since log of negative is undefined).

Q24 · IB Math AA HL · Integration · Hard

Evaluate ∫ x·e^x dx.

  • C) e^x(x + 1) + C

Answer: B) e^x(x - 1) + C. Using parts with u=x, dv=e^x dx: ∫x·e^x dx = x·e^x - ∫e^x dx = x·e^x - e^x = e^x(x-1) + C.

  • C) 16 m²

Answer: A) y = x² + 3. Integrate: y = x² + C. Use y(0)=3: C = 3. So y = x² + 3.
Q32 · IB Math AA HL · Vector Geometry · Medium

Find the dot product of vectors a = (2, -1, 3) and b = (4, 2, -1).

  • A) 3
  • B) 8

安装教程 Install Guide

Chrome / Edge（桌面 / Android）

  1. 点击上方 安装到桌面 按钮（地址栏右侧也会出现 ⊕ 图标）
  2. 在弹窗中点 安装
  3. 应用图标会出现在桌面 / 应用列表
  4. 离线状态下也能继续刷题

Safari（iOS / iPadOS）

  1. 点击底部分享按钮 ⬆
  2. 选择 添加到主屏幕
  3. 点 添加 完成
  4. 从主屏幕打开即为独立 App

注：iOS Safari 不支持 beforeinstallprompt，需手动操作。

Firefox

  1. 地址栏右侧会出现 ⊕ 主页图标
  2. 点击后选择 安装

注：Firefox 桌面版支持有限，建议使用 Chrome / Edge 体验完整 PWA。

Share Target（被其他 App 分享题库）

常见问题

Q: 安装按钮一直灰着？
需满足：HTTPS / 有 manifest.json / 已注册 Service Worker / 用户访问至少一次。
Q: 离线后数据会不会丢？
不会。答题数据存于 localStorage，刷新或离线均可用。
Q: 如何卸载？
桌面：右键 → 卸载；移动：长按图标 → 移除 / 删除。
Q: iOS 上能完整 PWA 吗？
能添加到主屏幕并独立运行，但 push notification / background sync 等 API 不支持。

TOEFL Syllabus v1

Reading + Listening + Speaking + Writing · 0-120

考试结构

Section 题型 题数 时长 分值
Reading 2 passages, 10q each 20q 35min 0-30
Listening 3 lectures (6q each) + 2 conversations (5q each) 28q 36min 0-30
Speaking 4 tasks (Independent + Integrated) 4 16min 0-30
Writing 1 Integrated (20min) + 1 Independent (10min) 2 29min (new format) 0-30
Total — — ~2h 0-120

知识点与技能

Section 知识点与技能
Reading Vocabulary, Main Idea, Detail, Inference, Rhetorical Purpose, Sentence Simplification, Insert Text, Prose Summary (10 question types)
Listening Main Idea, Detail, Purpose, Attitude, Organization, Connecting Content, Inference (7 question types)
Speaking Task 1 (Independent - opinion), Task 2 (Integrated - campus), Task 3 (Integrated - academic reading+listening), Task 4 (Integrated - academic listening)
Writing Integrated (read+listen+write 150-225 words), Independent (write 300+ words, opinion/argument)

Path B · IB

IGCSE / Pre-IB → IB Diploma → IELTS/TOEFL（+SAT 申美）

Path C · 美系

美高 9-10 → AP + 美高 11-12 → SAT/ACT + TOEFL

美国本土及国际美式高中路径。9-10 年级常规课程打底，11-12 年级选修 AP 大学课程，同时准备 SAT/ACT 和 TOEFL。申美国最直接，申英国可用 AP 替代 A-Level。

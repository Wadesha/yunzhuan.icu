IGCSE 化学

IGCSE Chemistry

CAIE 0620 / 0971

课程介绍 Course Overview

IGCSE 化学是 14-16 岁国际版 GCSE 化学课程，是 A-Level 化学、IB Chemistry 与医学/化工/材料类专业的衔接课程。课程涵盖物质状态、原子结构、化学计量、电化学、化学能、化学反应、酸碱盐、周期表、金属、环境化学与有机化学等内容，强调实验操作、化学方程式书写与摩尔计算。课程分 Core 与 Extended 两档，Extended 在摩尔计算与反应定量分析上要求更高。

IGCSE Chemistry is the international GCSE Chemistry course for students aged 14-16, serving as the standard preparation for A-Level Chemistry, IB Chemistry and science-oriented university programmes. It covers states of matter, atomic structure, stoichiometry, electrochemistry, chemical energetics, reactions, acids/bases/salts, the Periodic Table, metals, environmental chemistry and organic chemistry, with emphasis on practical work, equation writing and mole calculations.

章节大纲 Syllabus

  • Core1. States of matter
    物质状态 / 固液气粒子模型 / 扩散 / 状态变化 / 纯物质与混合物
  • Core2. Atoms, elements and compounds
    原子元素化合物 / 原子结构 / 同位素 / 离子键与共价键 / 化学式与方程式
  • Ext3. Stoichiometry
    化学计量（Extended 重点）/ 摩尔 / 摩尔浓度 / 限量反应物 / 产率与纯度计算
  • Ext4. Electrochemistry
    电化学 / 电解熔融物与水溶液 / 电解产物判断 / 电解的应用（电镀、铝冶炼）
  • Core5. Chemical energetics
    化学能 / 放热与吸热反应 / 化学键能量 / 燃烧 / 简单能量图
  • Ext6. Chemical reactions
    化学反应 / 反应速率 / 影响速率因素 / 可逆反应与平衡 / 催化剂 / 工业过程（哈伯法、接触法）
  • Core7. Acids, bases and salts
    酸碱盐 / 强弱酸碱 / pH / 中和反应 / 盐的制备与命名 / 指示剂
  • Core8. The Periodic Table
    周期表 / 周期律 / 第 I、II、VII、VIII 族 / 过渡金属 / 周期与族趋势
  • Core9. Metals
    金属 / 金属活动性 / 金属提取 / 合金 / 金属锈蚀与防护
  • Ext10. Chemistry of the environment
    环境化学（Extended）/ 水净化 / 空气与污染 / 温室效应 / 酸雨 / 全球碳循环
  • Ext11. Organic chemistry
    有机化学 / 烷烃烯烃 / 醇 / 羧酸 / 酯化 / 聚合物 / 加成与缩聚反应

Core 与 Extended 区分 Core vs Extended

CoreCore 档覆盖基本概念：物质状态、原子结构、化学键、能量变化、酸碱盐、周期表与金属。Core 不要求摩尔计算的复杂应用、电解定量分析、可逆反应平衡移动、有机化学命名等内容，最高成绩为 C。

ExtExtended 档在 Core 基础上扩展，新增完整的化学计量学（摩尔计算与限量反应物）、电化学定量分析、化学反应速率与平衡定量关系、环境化学（水与空气污染）以及有机化学（烷烯烃、醇、羧酸、酯化、聚合物）。Extended 最高可获 A* / 9，是衔接 A-Level 化学的推荐选择。

Core covers fundamental concepts without mole-based quantitative analysis, electrolysis products, equilibrium shifts, environmental chemistry or organic chemistry. Extended adds all of these plus full stoichiometry, reaching A* / 9 and is the recommended preparation for A-Level Chemistry.

Paper 1Multiple Choice (Core) · 45 min · 40 题 · 占 30%

适用衔接 Pathway

IGCSE 化学（建议选 Extended）是 A-Level 化学（CAIE 9701）、IB Chemistry HL/SL、医学/化工/材料/生物类专业的标准前置课程。完成 IGCSE 化学后可直接进入 A-Level AS 阶段，对化学键、摩尔计算、酸碱盐、有机化学有扎实基础的学生将更顺利地过渡到 A-Level 的物理化学、有机机理、化学平衡定量分析等高级内容。对于申请医学、化学工程、药学等专业的学生，IGCSE 化学建议取得 A* 或 9 等高分。

IGCSE Chemistry (Extended recommended) is the standard preparation for A-Level Chemistry 9701, IB Chemistry HL/SL and medical / chemical / materials science pathways. A solid foundation in bonding, stoichiometry and organic chemistry enables smooth transition to A-Level physical chemistry, organic mechanisms and quantitative equilibrium analysis.

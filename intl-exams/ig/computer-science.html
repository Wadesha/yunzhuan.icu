IGCSE 计算机科学

IGCSE Computer Science

CAIE 0478

课程介绍 Course Overview

IGCSE 计算机科学是 14-16 岁国际版 GCSE 计算机课程，是 A-Level Computer Science（CAIE 9618 / 9608）、IB Computer Science HL/SL 与计算机工程、人工智能、软件工程等专业的衔接课程。课程涵盖数据表示、硬件、软件、网络、算法设计与编程实践，强调计算思维、问题分解与编程实现。学生需掌握至少一门编程语言（Java / Python / Visual Basic）。0478 不设 Core/Extended 分档，所有考生均考同一份卷。

IGCSE Computer Science is the international GCSE Computing course for students aged 14-16, preparing students for A-Level Computer Science (9618 / 9608), IB Computer Science HL/SL and computer engineering / AI / software engineering pathways. It covers data representation, hardware, software, networks, algorithm design and programming practice, with emphasis on computational thinking, problem decomposition and implementation in at least one of Java / Python / Visual Basic.

章节大纲 Syllabus

Paper 1 理论部分（Computer Systems）

  • Core1. Data representation
    数据表示 / 二进制与十六进制 / 字符编码 / 图像与声音的数字化
  • Core2. Data transmission
    数据传输 / 串行与并行 / 错误检测 / 加密与压缩
  • Core3. Hardware
    硬件 / CPU 结构与功能 / 内存与存储 / 输入输出设备
  • Core4. Software
    软件 / 系统软件与应用软件 / 操作系统 / 高级语言与翻译器
  • Ext5. The internet and its uses
    互联网 / 网络结构与协议 / IP 地址与域名 / HTML 与 CSS / 网络安全
  • Ext6. Automated and emerging technologies
    自动化与新兴技术 / 人工智能 / 机器人 / 生物识别 / 自动驾驶的伦理与社会影响

Paper 2 算法与编程部分（Algorithms, Programming and Logic）

  • Core7. Algorithm design and problem-solving
    算法设计与问题解决 / 流程图与伪代码 / 顺序选择循环结构 / 算法可追溯性与调试
  • Ext8. Programming
    编程 / 变量与数据类型 / 输入输出 / 子程序与参数 / 数组与字符串 / 文件处理
  • Ext9. Databases
    数据库 / 关系数据库 / 主键与外键 / SQL 查询与 CRUD 操作
  • Ext10. Boolean logic
    布尔逻辑 / 逻辑门（AND OR NOT） / 真值表 / 逻辑电路简化

Core 与 Extended 区分 Core vs Extended

Ext注意：IGCSE Computer Science（0478 / 0984）不设 Core/Extended 两档，所有考生均考相同 Paper 1 与 Paper 2，统一评 A* - G 或 9-1。难度梯度通过题型与代码复杂度体现，而非通过分档。

具体而言：Paper 1（理论）覆盖数据表示、硬件、软件、网络与新兴技术等概念性内容，相对偏记忆与理解；Paper 2（算法与编程）要求阅读、追踪与编写实际代码、SQL 与逻辑电路分析，复杂度更高。本页主题标签按内容相对难度区分：基础概念（数据表示、硬件、软件、算法设计入门）标 core；网络、新兴技术、完整编程、数据库与布尔逻辑标 ext。

Computer Science 0478 / 0984 has no Core/Extended tier; all candidates sit the same Paper 1 (theory) and Paper 2 (algorithms, programming and logic). Difficulty gradients reflect question type and code complexity: Paper 2 demands code tracing, writing and SQL/logic analysis. Topics 1-4 and 7 are foundational; 5, 6, 8, 9 and 10 are more analytical.

考试结构 Exam Structure (CAIE 0478 / 0984)

Paper 1Computer Systems 计算机系统 · 1h30m · 60 分 · 占 60%
Paper 2Algorithms, Programming and Logic 算法编程与逻辑 · 1h30m · 50 分 · 占 40%

注：两份卷面均覆盖全部 10 个主题；Paper 2 含代码追踪、伪代码编写、SQL 查询与逻辑电路分析；无实操上机考试；无 Core/Extended 选择。

适用衔接 Pathway

IGCSE Computer Science 是 A-Level Computer Science（CAIE 9618，旧 9608）、IB Computer Science HL/SL 与计算机工程、人工智能、软件工程、数据科学等专业的标准前置课程。完成 IGCSE CS 后可直接进入 A-Level AS 阶段，对数据表示、算法思维与一门编程语言（Python / Java / VB）有扎实基础的学生将更顺利地过渡到 A-Level 的面向对象编程（OOP）、数据结构、操作系统、网络协议栈与计算理论等高级内容。对申请计算机科学、AI、软件工程等专业的学生，IGCSE CS 建议取得 A* 或 9 等高分，并配合 IGCSE 数学 Extended 同期高分。

IGCSE Computer Science is the standard preparation for A-Level Computer Science 9618 (formerly 9608), IB Computer Science HL/SL and CS / AI / software engineering / data science pathways. A solid foundation in data representation, algorithmic thinking and one of Python / Java / VB enables smooth transition to A-Level OOP, data structures, operating systems, networking and theory of computation.

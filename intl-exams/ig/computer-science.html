IGCSE Computer Science

IGCSE 计算机科学

CAIE 0478

Course Overview 课程介绍

IGCSE 计算机科学 14-16 岁，覆盖数据表示/硬件/网络/算法/编程，无 Core/Extended 分档，A-Level/IB 衔接。

IGCSE Computer Science is the international GCSE Computing course for students aged 14-16, preparing students for A-Level Computer Science (9618 / 9608), IB Computer Science HL/SL and computer engineering / AI / software engineering pathways. It covers data representation, hardware, software, networks, algorithm design and programming practice, with emphasis on computational thinking, problem decomposition and implementation in at least one of Java / Python / Visual Basic. There is no Core/Extended tier; all candidates sit the same papers.

Syllabus 章节大纲

Paper 1 Theory (Computer Systems)

  • Core1. Data representation
    Data representation / binary and hexadecimal / character encoding / digital images and sound
  • Core2. Data transmission
    Data transmission / serial and parallel / error detection / encryption and compression
  • Core3. Hardware
    Hardware / CPU structure and function / memory and storage / input and output devices
  • Core4. Software
    Software / system software and application software / operating systems / high-level languages and translators
  • Ext5. The internet and its uses
    The internet / network structure and protocols / IP addresses and domain names / HTML and CSS / network security
  • Ext6. Automated and emerging technologies
    Automated and emerging technologies / AI / robotics / biometrics / ethical and social impact of autonomous vehicles

Paper 2 Algorithms, Programming and Logic

  • Core7. Algorithm design and problem-solving
    Algorithm design and problem-solving / flowcharts and pseudocode / sequence, selection and iteration / trace tables and debugging
  • Ext8. Programming
    Programming / variables and data types / input and output / subroutines and parameters / arrays and strings / file handling
  • Ext9. Databases
    Databases / relational databases / primary and foreign keys / SQL queries and CRUD operations
  • Ext10. Boolean logic
    Boolean logic / logic gates (AND OR NOT) / truth tables / logic-circuit simplification

Core vs Extended Core 与 Extended 区分

0478 不设 Core/Extended 分档，难度由题型与代码复杂度区分，Paper 2 要求最高。

ExtNote: IGCSE Computer Science (0478 / 0984) has no Core/Extended tier; all candidates sit the same Paper 1 and Paper 2, graded A*-G or 9-1. Difficulty gradients reflect question type and code complexity rather than tiering.

Specifically: Paper 1 (theory) covers conceptual content such as data representation, hardware, software, networks and emerging technologies, leaning towards memory and understanding; Paper 2 (algorithms and programming) requires reading, tracing and writing actual code, plus SQL and logic-circuit analysis, with higher complexity. Topic tags here reflect relative difficulty: foundational concepts (data representation, hardware, software, algorithm-design basics) are tagged core; networks, emerging technologies, full programming, databases and Boolean logic are tagged ext.

Exam Structure (CAIE 0478 / 0984) 考试结构

Paper 1Computer Systems · 1h30m · 60 marks · 60%
Paper 2Algorithms, Programming and Logic · 1h30m · 50 marks · 40%

Note: Both papers cover all 10 topics; Paper 2 includes code tracing, pseudocode writing, SQL queries and logic-circuit analysis; there is no practical on-computer exam; no Core/Extended choice.

Pathway 适用衔接

衔接 A-Level CS 9618、IB CS，CS/AI/软件工程建议 A*/9 并配 IGCSE 数学 Extended。

IGCSE Computer Science is the standard preparation for A-Level Computer Science (CAIE 9618, formerly 9608), IB Computer Science HL/SL and CS / AI / software engineering / data science pathways. After completing IGCSE CS, students progress directly to A-Level AS; those with a solid foundation in data representation, algorithmic thinking and one programming language (Python / Java / VB) transition more smoothly to A-Level OOP, data structures, operating systems, networking and theory of computation. For students applying to computer science, AI or software engineering, an A* or 9 in IGCSE CS is recommended, alongside a high grade in IGCSE Mathematics Extended.

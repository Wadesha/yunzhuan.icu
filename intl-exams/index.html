International Curriculum Exams · AL / IG / IB / AP

本栏目汇总用于申请海外大学本科的主流国际课程考试体系，包括 A-Level (CAIE/Edexcel/AQA)、IGCSE、IB Diploma 以及 AP。每个体系下按学科组织，物理等热门科目在一页内按章节展开，便于横向对比各体系的覆盖范围、难度梯度与考试结构。
A-Level Advanced Level 英国高中高级课程，2 年制（AS + A2），全球大学广泛认可。CAIE / Edexcel / AQA 等考试局。 IGCSE International GCSE 14-16 岁国际版 GCSE，A-Level 与 IB 之前的衔接课程。分 Core 与 Extended 两档。 IB Diploma International Baccalaureate 2 年制国际文凭课程，6 组学科 + TOK + EE + CAS。多数科目分 HL（高阶）与 SL（标准）。 AP Advanced Placement 美国大学理事会主办，单科 1 年制考试，可换算大学学分。物理分 Physics 1 / 2 / C-Mech / C-EM。

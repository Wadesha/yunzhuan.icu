A-Level 计算机科学

A-Level Computer Science

CAIE 9618 / Edexcel 9CS0 / AQA 7517

课程介绍 Course Overview

A-Level 计算机科学是英国高中高级课程，分 AS（第一年）与 A2（第二年）两阶段。课程涵盖计算机原理、数据表示与传输、硬件软件、数据库、网络安全、算法设计与编程实践。A2 阶段引入人工智能与高级算法。强调计算思维、问题求解与编程实现。是申请计算机科学、软件工程、人工智能、数据科学、信息工程等专业的核心基础科目。

A-Level Computer Science is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers computer principles, data representation and transmission, hardware & software, databases, cybersecurity, algorithm design and programming practice. A2 introduces artificial intelligence and advanced algorithms. It emphasises computational thinking, problem solving and programming. A core subject for computer science, software engineering, AI, data science and information engineering.

AS 阶段章节 AS Syllabus

  • AS1. Information Representation
    信息表示 / 二进制十六进制 / 数制转换 / 字符编码 / 图像与声音表示
  • AS2. Data Transmission
    数据传输 / 传输媒介 / 串并行传输 / 校验与纠错 / 数据压缩
  • AS3. Hardware
    硬件 / 计算机结构 / CPU 与寄存器 / 存储器层次 / 输入输出设备
  • AS4. Software and Software Development
    软件与软件开发 / 系统软件应用软件 / 翻译器 / 软件开发生命周期
  • AS5. Relational Database Modelling
    关系数据库建模 / 实体关系图 / 范式化 / 主外键 / SQL 基础
  • AS6. System Software
    系统软件 / 操作系统功能 / 文件管理 / 中断与调度 / 虚拟内存
  • AS7. Security, Privacy and Data Integrity
    安全、隐私与数据完整性 / 加密 / 防火墙 / 数据验证 / 隐私保护
  • AS8. Ethics and Ownership
    伦理与所有权 / 知识产权 / 软件版权 / 人工智能伦理 / 数字鸿沟
  • AS9. Algorithm Design and Problem-solving
    算法设计与问题求解 / 流程图伪代码 / 算法效率 / 抽象与分解
  • AS10. Data Structures and Data Types
    数据结构与类型 / 数组记录链表 / 栈与队列 / 静态动态结构
  • AS11. Programming and Software Development
    编程与软件开发 / 变量常量 / 控制结构 / 子程序 / 模块化设计
  • AS12. Algorithms (Linear Search, Bubble Sort)
    基础算法 / 顺序与二分查找 / 冒泡排序 / 算法复杂度分析

A2 阶段章节 A2 Syllabus

  • A213. Data Representation (Advanced)
    数据表示进阶 / 浮点数表示 / 用户定义数据类型 / 文件组织
  • A214. Communication and Internet Technologies
    通信与互联网技术 / 网络协议 / TCP/IP / HTTP/DNS / 网络拓扑
  • A215. Hardware (Advanced)
    硬件进阶 / 并行处理 / GPU / 虚拟化 / 专用处理器
  • A216. System Software and Virtual Machines
    系统软件与虚拟机 / 虚拟机原理 / 解释执行 / 中断处理进阶
  • A217. Security
    安全进阶 / 公钥加密 / 数字签名 / 安全协议 / 入侵检测
  • A218. Artificial Intelligence
    人工智能 / AI 定义与分类 / 机器学习基础 / 神经网络 / 专家系统
  • A219. Computational Thinking and Problem-solving
    计算思维与问题求解 / 递归 / 分治 / 动态规划 / 算法分析
  • A220. Algorithms (Advanced)
    算法进阶 / 插入与快速排序 / Dijkstra / 树遍历 / 哈希查找
  • A221. Recursion and Abstract Data Types
    递归与抽象数据类型 / 链表树图 / 递归实现 / ADT 设计
  • A222. Programming Paradigms
    编程范式 / 面向对象 / 函数式 / 事件驱动 / 范式比较
  • A223. File Organisation and Database (Advanced)
    文件组织与数据库进阶 / 顺序索引文件 / 事务与并发 / SQL 进阶
  • A224. Practical Programming Project
    编程实操 / 上机编程考试 / 程序设计 / 调试测试 / 文档化

考试结构 Exam Structure (CAIE 9618)

Paper 1AS 理论基础 · 1h30m · 占 AS 50% / A-Level 25%
Paper 2AS 基础问题求解与编程 · 2h · 占 AS 50% / A-Level 25%
Paper 3A2 高级理论 · 1h30m · 占 A-Level 25%
Paper 4A2 实操（上机编程） · 2h30m · 占 A-Level 25%

适用专业与衔接 Suitable Majors

A-Level 计算机科学是计算机科学、软件工程、人工智能、数据科学、网络安全、信息系统、信息工程、游戏开发、电子电气工程等专业的重要基础科目。多数英国大学计算机类专业将 A-Level 计算机科学视为推荐科目（常与数学搭配）。课程为大学数据结构、算法分析、操作系统、数据库系统等课程提供扎实前置基础。

A-Level Computer Science is a key subject for computer science, software engineering, AI, data science, cybersecurity, information systems, information engineering, game development and electrical & electronic engineering. Most UK university CS programmes recommend A-Level Computer Science (often paired with Mathematics). It provides a solid foundation for university data structures, algorithm analysis, operating systems and database systems.

课程介绍 Course Overview

A-Level 物理是英国高中高级课程，分 AS（第一年）与 A2（第二年）两阶段，两年完成完整 A-Level。课程涵盖经典力学、电磁学、波动、热学、量子物理与核物理，强调实验技能与数据处理。是申请工程、物理、计算机、医学等理工科专业的核心科目。

A-Level Physics is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers mechanics, electromagnetism, waves, thermal physics, quantum physics and nuclear physics, with strong emphasis on practical skills and data analysis. A core subject for engineering, physics, CS and medicine applicants.

AS 阶段章节 AS Syllabus

  • AS1. Physical Quantities and Units
    物理量与单位 / SI 制 / 标量矢量 / 不确定度与误差分析
  • AS2. Kinematics
    运动学 / 位移速度加速度 / 运动方程 / 图像分析
  • AS3. Dynamics
    动力学 / 牛顿运动定律 / 动量与冲量 / 力的合成与分解
  • AS4. Forces, Density and Pressure
    力 / 密度与压强 / 浮力 / 力矩平衡
  • AS5. Work, Energy and Power
    功 / 动能与势能 / 能量守恒 / 功率 / 效率
  • AS6. Deformation of Solids
    固体形变 / 胡克定律 / 杨氏模量 / 弹性势能
  • AS7. Waves
    波 / 行波与驻波 / 横纵波 / 波速波长频率 / 折射与反射
  • AS8. Superposition
    波的叠加 / 干涉 / 衍射 / 双缝实验 / 驻波形成
  • AS9. Electric Fields
    电场 / 库仑定律 / 电场强度 / 电势 / 均匀电场
  • AS10. D.C. Circuits
    直流电路 / 电阻串并联 / 基尔霍夫定律 / 内阻 / 电功率
  • AS11. Particle Physics
    粒子物理 / 基本粒子 / 夸克模型 / β 衰变 / 光电效应

考试结构 Exam Structure (CAIE 9702)

Paper 1AS 多选题 · 1h15m · 占 AS 31% / A-Level 15.5%
Paper 2AS 简答题 · 1h15m · 占 AS 46% / A-Level 23%
Paper 3AS 实验技能 · 2h · 占 AS 23% / A-Level 11.5%
Paper 4A2 结构题 · 2h · 占 A-Level 38.5%
Paper 5A2 实验规划与分析 · 1h15m · 占 A-Level 11.5%

实验技能 Practical Skills

Paper 3 为实操考试，考察实验设计与数据处理；Paper 5 不做实操，考察实验设计与分析评估。两类考试均要求掌握：仪器使用、误差分析、不确定度传递、作图与线性化、显著性判断。

Paper 3 is a hands-on practical exam; Paper 5 evaluates planning, analysis and evaluation without lab work. Both require instrument handling, error analysis, uncertainty propagation, graphing and linearization.

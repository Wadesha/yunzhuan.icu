A-Level History

CAIE 9489 / Edexcel 9HI0 / AQA 7042

课程介绍 Course Overview

A-Level 历史是英国高中高级课程，分 AS（第一年）与 A2（第二年）两阶段。课程涵盖近现代欧洲史、世界史与专题深度研究，强调史料分析、史观辩论与历史论证写作。是申请历史、政治、国际关系、法学、新闻、公共政策、人类学等人文社科专业的核心基础科目。

A-Level History is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers modern European and world history and thematic depth studies, with strong emphasis on source analysis, historiographical debate and historical essay writing. A core subject for history, politics, international relations, law, journalism, public policy and anthropology.

AS 阶段章节 AS Syllabus

  • AS1. Liberalism and Nationalism in Europe 1848-1871
    欧洲自由主义与民族主义 1848-1871 / 1848 革命 / 民族统一运动 / 自由主义思潮
  • AS2. The Origins of World War I 1890-1914
    一战起源 1890-1914 / 同盟体系 / 殖民竞争 / 军备竞赛 / 七月危机
  • AS3. The Russian Revolution 1894-1924
    俄国革命 1894-1924 / 沙皇末期 / 1917 革命 / 布尔什维克夺权 / 内战
  • AS4. The Inter-war Years and the Great Depression
    两次大战之间与大萧条 / 凡尔赛体系 / 经济危机 / 极权主义兴起
  • AS5. Source Analysis Skills
    史料分析技能 / 一手史料 / 史料价值评估 / 起源目的受众 / 交叉印证
  • AS6. Historical Interpretation
    历史解释 / 史观比较 / 史学家观点 / 解释分歧原因
  • AS7. Modern European State Depth Study
    现代欧洲国家深度研究 / 德国 / 意大利 / 西班牙等选定国家政治演变
  • AS8. The Holocaust 1941-1945
    大屠杀 1941-1945 / 反犹政策演进 / 灭绝营体制 / 受害者视角 / 史学争议
  • AS9. Asian State Depth Study
    亚洲国家深度研究 / 日本明治维新 / 中国近代变革 / 印度独立运动
  • AS10. Essay Writing and Argument Construction
    论文写作与论证构建 / 论点提出 / 证据组织 / 因果分析 / 反驳与综合

A2 阶段章节 A2 Syllabus

    二战与冷战起源 / 战时同盟关系 / 雅尔塔波茨坦 / 战后欧洲格局
  • A212. The Cold War 1947-1991
    冷战 1947-1991 / 柏林危机 / 古巴导弹危机 / 越战 / 戈尔巴乔夫改革
  • A213. Decolonisation and Post-colonial World
    非殖民化与后殖民世界 / 殖民体系瓦解 / 第三世界兴起 / 新兴国家挑战
  • A214. The United States 1945-1990
    美国 1945-1990 / 民权运动 / 越战时期 / 尼克松水门 / 里根时代
  • A215. China 1900-1989
    中国 1900-1989 / 清末民初 / 国共内战 / 新中国建立 / 改革开放
  • A216. Historical Investigation (Coursework)
    历史调查（coursework）/ 选题论证 / 史料研究 / 独立论文写作
  • A217. Interpretations of History
    史学解释 / 史学派别 / 修正派 / 后修正派 / 史学方法比较
  • A218. The Causes and Consequences of Wars
    战争原因与后果 / 战争性质演变 / 总体战 / 战后重建与社会变迁
  • A219. Economic and Social Change in the 20th Century
    20 世纪经济与社会变迁 / 福利国家 / 性别角色 / 消费社会 / 文化革命
  • A220. Comparative and Thematic History
    比较与专题史 / 跨地域比较 / 长时段主题 / 革命、帝国、民主化等专题

考试结构 Exam Structure (CAIE 9489)

Component 1文献题（Document Question）· 1h · 占 AS 40% / A-Level 20%
Component 2概要研究（Outline Study）· 1h30m · 占 AS 60% / A-Level 25%
Component 3历史调查（Coursework）· 3000-4000 字 · 占 A-Level 20%
Component 4深度研究（Depth Study）· 1h30m · 占 A-Level 35%

适用专业与衔接 Suitable Majors

A-Level 历史是历史学、政治学、国际关系、法学、新闻、公共政策、人类学、考古学、博物馆学、教育学等人文社科专业的核心基础科目。多数英国罗素集团大学将 A-Level 历史视为传统学术科目。课程为大学史学方法、政治思想史、国际关系史等课程提供扎实前置基础，并培养批判性阅读与论证写作能力。

A-Level History is a core subject for history, politics, international relations, law, journalism, public policy, anthropology, archaeology, museum studies and education. Most UK Russell Group universities regard A-Level History as a traditional academic subject. It provides a solid foundation for university historiographical method, political thought, and international history, and develops critical reading and argumentative writing.

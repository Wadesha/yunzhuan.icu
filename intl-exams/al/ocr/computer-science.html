A-Level Computer Science (OCR)

A-Level 计算机科学（OCR）

OCR H046 (AS) / H446 (A-Level)

Course Overview 课程介绍

OCR A-Level 计算机科学，线性结构，含计算原理、算法、编程与项目，强调计算思维。

OCR A-Level Computer Science (H446) is a linear two-year course assessed by two written papers and one programming project at the end of Year 13. OCR A-Level has moved to a linear structure since 2015, so all exams are taken at the end of the course. The specification covers computer systems (processors, software, data exchange, data structures, legal and ethical issues), algorithms and programming (computational thinking, problem solving, standard algorithms, programming paradigms), plus an independently developed programming project. A core subject for computer science, software engineering, AI, data science and engineering applicants.

AS / Year 1 Syllabus AS 阶段章节

  • ASComponent 01: Computing Principles
    Characteristics of contemporary processors, software and software development, exchanging data (compression, encryption, databases), data types and structures, Boolean algebra, legal, moral and ethical issues
  • ASComponent 02: Algorithms and Problem Solving
    Computational thinking, programming techniques, standard algorithms (search, sort, recursion), computer architecture and assembly language, programming project preparation

A2 / Year 2 Syllabus A2 阶段章节

  • A2Component 01: Computer Systems (Advanced)
    Operating systems, the Internet and TCP/IP, data structures (lists, trees, hash tables, graphs), finite state machines, Boolean algebra simplification, advanced databases (normalisation, SQL)
  • A2Component 02: Algorithms and Programming (Advanced)
    Path finding (Dijkstra, A*), dynamic programming, object-oriented and functional paradigms, recursion (advanced), assembly language, big-O analysis of algorithms
  • A2Component 03: Programming Project (Coursework)
    An independently specified, designed, developed, tested and evaluated solution to a real problem; documentation, programming language chosen by the candidate

Suitable Majors & Pathway 适用专业与衔接

计算机科学、软件工程、AI 与数据科学的核心科目，强调计算思维与编程实现。

A-Level Computer Science is a key subject for computer science, software engineering, artificial intelligence, data science, cybersecurity, games development, electronics and engineering. Most UK computer science programmes welcome A-Level Computer Science and many require A-Level Mathematics alongside it. The course develops computational thinking, algorithm design, programming skills and project management, and pairs naturally with A-Level Mathematics, Further Mathematics or Physics for applicants to competitive CS and engineering degrees.

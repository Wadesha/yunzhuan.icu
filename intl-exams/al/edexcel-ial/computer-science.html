A-Level Computer Science (Edexcel IAL)

A-Level 计算机科学（Edexcel IAL）

Edexcel IAL WCO11-12

Course Overview 课程介绍

Edexcel IAL 计算机科学按 Unit 模块化考试，可重考单模块，计算机、软件工程与人工智能专业核心科目。

Edexcel International A-Level Computer Science is a modular course assessed across two units covering the principles of computer science and practical problem solving with programming. Students sit each Unit exam separately and may retake individual units. Content spans computational thinking, programming, data representation, computer architecture, networks, databases and algorithms, with a strong practical programming focus. A core subject for computer science, software engineering, AI and data science applicants.

Key Facts 基本信息

Grading (评分)A* - E for full A-Level; a - e for AS

Programming (编程)Practical programming and problem-solving embedded in both units

AS Syllabus AS 阶段章节（Unit 1）

  • Unit 1Computational Thinking
    Decomposition, pattern recognition, abstraction, algorithm design and pseudocode
  • Unit 1Programming Techniques
    Data types, variables, sequence/selection/iteration, subprograms, parameter passing, recursion
  • Unit 1Data Structures and Algorithms
    Arrays, lists and records; linear and binary search, bubble and merge sort, algorithm efficiency
  • Unit 1Data Representation
    Binary and hexadecimal number systems, ASCII and Unicode, representing images and sound, data compression
  • Unit 1Computer Architecture
    Von Neumann architecture, CPU components and the fetch-execute cycle, memory and storage
  • Unit 1Boolean Logic and Networks
    Logic gates and Boolean algebra, networks, protocols and the TCP/IP stack

A2 Syllabus A2 阶段章节（Unit 2）

  • Unit 2Computational Problem Solving
    Decomposing problems, designing algorithms, computational complexity and tractability
  • Unit 2Programming Paradigms
    Procedural and object-oriented programming, classes and objects, encapsulation, inheritance and polymorphism
  • Unit 2Advanced Data Structures and Algorithms
    Stacks, queues, linked lists, trees and graphs; tree traversal, pathfinding and algorithm efficiency
  • Unit 2Software Development
    Software development lifecycle, testing strategies, debugging, robustness and maintainability
  • Unit 2Databases and Web Technologies
    Relational databases, normalisation and SQL, HTML, CSS and client-server web architecture
  • Unit 2Networks and Cyber Security
    Network topologies, encryption, threats and vulnerabilities, security policies and data protection

Exam Structure (Edexcel IAL WCO11-12) 考试结构

Unit 1 (WCO11)Principles of Computer Science · 1h30m · 50% of IAL (100% of AS)
Unit 2 (WCO12)Problem Solving and Programming · 2h · 50% of IAL
Modular FeatureModular structure, unit-by-unit assessment, single unit retake allowed

Suitable Majors & Pathway 适合专业与升学路径

适合计算机科学、软件工程、人工智能、数据科学与工程专业，是英国计算机相关专业的核心科目。

Computer Science is essential for computer science, software engineering, artificial intelligence, data science, cybersecurity and games development. Paired with Mathematics and Further Mathematics it opens pathways to top STEM universities. The modular Edexcel IAL format lets students retake individual units to strengthen their final grade.

A-Level 心理学

A-Level Psychology

CAIE 9990 / Edexcel 9PS0 / AQA 7182

课程介绍 Course Overview

A-Level 心理学是英国高中高级课程，分 AS（第一年）与 A2（第二年）两阶段。课程涵盖生物、认知、社会、学习四大心理学取向，并以研究方法贯穿全程。A2 阶段深入异常、消费、健康、组织等应用领域。强调实证研究、批判性评估与心理学方法学。是申请心理学、神经科学、教育、社会工作、市场研究、人力资源等专业的核心基础科目。

A-Level Psychology is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers biological, cognitive, social and learning approaches, with research methods running throughout. A2 explores applied areas such as abnormality, consumer, health and organisational psychology. It emphasises empirical research, critical evaluation and psychological methodology. A core subject for psychology, neuroscience, education, social work, market research and HR.

AS 阶段章节 AS Syllabus

  • AS1. Research Methodology
    研究方法 / 实验设计 / 观察法调查法个案研究 / 取样 / 伦理
  • AS2. Data Analysis and Statistics
    数据分析与统计 / 描述统计 / 推论统计 / 显著性检验 / 相关分析
  • AS3. The Biological Approach
    生物学取向 / 神经元与神经递质 / 大脑结构与功能 / 内分泌系统 / 进化
  • AS4. The Cognitive Approach
    认知取向 / 记忆模型 / 短期长期记忆 / 遗忘理论 / 思维与问题解决
  • AS5. The Learning Approach
    学习取向 / 经典条件反射 / 操作条件反射 / 社会学习理论 / 行为主义
  • AS6. The Social Approach
    社会取向 / 从众与服从 / 偏见与歧视 / 群体动力学 / 社会认知
  • AS7. Issues and Debates in Psychology
    心理学的议题与争议 / 先天与后天 / 自由意志与决定论 / 还原论 / 文化偏差
  • AS8. Classic Studies in Psychology
    心理学经典研究 / 巴甫洛夫 / 斯金纳 / 米尔格拉姆 / 阿希 / 洛夫特斯等
  • AS9. Ethical Issues and Animal Research
    伦理问题与动物研究 / 知情同意 / 欺骗与隐私 / 动物实验伦理准则
  • AS10. Reliability, Validity and Generalisability
    信度、效度与可推广性 / 测量信度 / 内外效度 / 跨文化推广

A2 阶段章节 A2 Syllabus

  • A211. Abnormality (Specialist Option)
    异常心理学 / 异常定义与诊断 / 抑郁焦虑 / 精神分裂 / 治疗方法

  • A213. Health (Specialist Option)
    健康心理学 / 压力与应对 / 健康行为 / 患者依从性 / 疼痛管理
  • A214. Organisations (Specialist Option)
    组织心理学 / 工作动机 / 领导风格 / 工作满意度 / 团队与冲突
  • A215. Application of Approaches
    取向的应用 / 用四大取向解释应用领域现象 / 理论与实践整合
  • A216. Advanced Research Methods
    进阶研究方法 / 准实验 / 相关设计 / 纵向研究 / 跨文化比较
  • A217. Inferential Statistics (Advanced)
    进阶推论统计 / 非参数检验 / 曼-惠特尼 / 维尔科克森 / 卡方
  • A218. Issues in Application
    应用中的议题 / 心理学应用伦理 / 应用有效性 / 文化适应性
  • A219. Contemporary Studies
    当代研究 / 应用领域近期实证 / 研究方法评析 / 证据强度
  • A220. Synoptic Evaluation
    综合评估 / 跨取向整合 / 多角度论证 / 综合评价能力

适用专业与衔接 Suitable Majors

A-Level 心理学是心理学、神经科学、行为科学、教育学、社会工作、人力资源管理、市场研究、消费者研究、临床心理学、咨询等专业的重要基础科目。多数英国大学心理学专业将 A-Level 心理学视为推荐或必修科目。课程为大学实验心理学、心理统计、变态心理学等课程提供扎实前置基础。

A-Level Psychology is a key subject for psychology, neuroscience, behavioural science, education, social work, HR, market research, consumer research, clinical psychology and counselling. Most UK university psychology programmes recommend or require A-Level Psychology. It provides a solid foundation for university experimental psychology, psychological statistics and abnormal psychology.

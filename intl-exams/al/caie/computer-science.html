A-Level Computer Science

A-Level 计算机科学

CAIE 9618

Course Overview 课程介绍

CAIE 高级计算机科学，涵盖原理、算法与编程实践，A2 引入人工智能。

A-Level Computer Science is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers computer principles, data representation and transmission, hardware & software, databases, cybersecurity, algorithm design and programming practice. A2 introduces artificial intelligence and advanced algorithms. It emphasises computational thinking, problem solving and programming. A core subject for computer science, software engineering, AI, data science and information engineering.

AS Syllabus AS 阶段章节

  • AS1. Information Representation
    Binary and hexadecimal, number system conversion, character encoding, image and sound representation
  • AS2. Data Transmission
    Transmission media, serial and parallel transmission, error detection and correction, data compression
  • AS3. Hardware
    Computer architecture, CPU and registers, memory hierarchy, I/O devices
  • AS4. Software and Software Development
    System and application software, translators, software development lifecycle
  • AS5. Relational Database Modelling
    Entity-relationship diagrams, normalisation, primary and foreign keys, basic SQL
  • AS6. System Software
    Operating system functions, file management, interrupts and scheduling, virtual memory
  • AS7. Security, Privacy and Data Integrity
    Encryption, firewalls, data validation, privacy protection
  • AS8. Ethics and Ownership
    Intellectual property, software copyright, AI ethics, digital divide
  • AS9. Algorithm Design and Problem-solving
    Flowcharts and pseudocode, algorithm efficiency, abstraction and decomposition
  • AS10. Data Structures and Data Types
    Arrays, records, linked lists, stacks and queues, static and dynamic structures
  • AS11. Programming and Software Development
    Variables and constants, control structures, subroutines, modular design
  • AS12. Algorithms (Linear Search, Bubble Sort)
    Linear and binary search, bubble sort, algorithm complexity analysis

A2 Syllabus A2 阶段章节

  • A213. Data Representation (Advanced)
    Floating point representation, user-defined data types, file organisation
  • A214. Communication and Internet Technologies
    Network protocols, TCP/IP, HTTP/DNS, network topologies
  • A215. Hardware (Advanced)
    Parallel processing, GPU, virtualisation, dedicated processors
  • A216. System Software and Virtual Machines
    Virtual machine principles, interpreted execution, advanced interrupt handling
  • A217. Security
    Public key encryption, digital signatures, security protocols, intrusion detection
  • A218. Artificial Intelligence
    AI definition and classification, machine learning basics, neural networks, expert systems
  • A219. Computational Thinking and Problem-solving
    Recursion, divide and conquer, dynamic programming, algorithm analysis
  • A220. Algorithms (Advanced)
    Insertion and quick sort, Dijkstra, tree traversal, hash lookup
  • A221. Recursion and Abstract Data Types
    Linked lists, trees, graphs, recursive implementation, ADT design
  • A222. Programming Paradigms
    Object-oriented, functional, event-driven, paradigm comparison
  • A223. File Organisation and Database (Advanced)
    Sequential and indexed files, transactions and concurrency, advanced SQL
  • A224. Practical Programming Project
    On-computer programming exam, program design, debugging and testing, documentation

Exam Structure (CAIE 9618) 考试结构

Paper 1AS Theory Fundamentals · 1h30m · 50% of AS / 25% of A-Level
Paper 2AS Basic Problem-solving and Programming · 2h · 50% of AS / 25% of A-Level
Paper 3A2 Advanced Theory · 1h30m · 25% of A-Level
Paper 4A2 Practical (on-computer programming) · 2h30m · 25% of A-Level

Suitable Majors 适用专业与衔接

计算机科学、软件工程、人工智能、数据科学等专业的核心基础科目。

A-Level Computer Science is a key subject for computer science, software engineering, AI, data science, cybersecurity, information systems, information engineering, game development and electrical & electronic engineering. Most UK university CS programmes recommend A-Level Computer Science (often paired with Mathematics). It provides a solid foundation for university data structures, algorithm analysis, operating systems and database systems.

A-Level 数学

A-Level Mathematics

CAIE 9709 / Edexcel 9MA0 / AQA 7357

课程介绍 Course Overview

A-Level 数学是英国高中高级课程，分 AS（第一年）与 A2（第二年）两阶段。课程涵盖纯数学、力学、概率与统计三大板块，强调代数技巧、函数建模与问题求解能力。是申请数学、工程、物理、计算机、经济、金融、统计等专业的核心基础科目。

A-Level Mathematics is a UK advanced secondary course split into AS (Year 1) and A2 (Year 2). It covers pure mathematics, mechanics, and probability & statistics, with strong emphasis on algebraic technique, function modelling and problem solving. A core subject for mathematics, engineering, physics, computer science, economics, finance and statistics applicants.

AS 阶段章节 AS Syllabus

  • AS1. Quadratics
    二次函数 / 判别式 / 配方 / 求根公式 / 不等式
  • AS2. Functions
    函数 / 定义域值域 / 复合函数 / 反函数 / 图像变换
  • AS3. Coordinate Geometry
    坐标几何 / 直线方程 / 圆方程 / 距离与中点
  • AS4. Circular Measure
    弧度制 / 弧长与扇形面积 / 角度弧度换算
  • AS5. Trigonometry
    三角函数 / 三角恒等式 / 三角方程 / 正弦余弦定理
  • AS6. Vectors
    向量 / 二维向量 / 加减与数乘 / 模与单位向量 / 点积
  • AS7. Series
    级数 / 等差与等比数列 / 求和公式 / 二项式展开
  • AS8. Differentiation
    微分 / 导数定义 / 幂函数求导 / 切线法线 / 极值与单调性
  • AS9. Integration
    积分 / 不定积分 / 定积分 / 曲线下面积 / 旋转体体积
  • AS10. Forces and Equilibrium
    力学：力与平衡 / 力的合成与分解 / 平衡条件 / 摩擦力
  • AS11. Kinematics of Motion
    力学：运动学 / 位移速度加速度 / 匀加速运动方程 / 微积分应用
  • AS12. Representation of Data and Probability
    统计：数据表示与概率 / 离散连续数据 / 排列组合 / 概率基础
  • AS13. Discrete Random Variables
    统计：离散随机变量 / 概率分布 / 期望方差 / 二项分布
  • AS14. Normal Distribution
    统计：正态分布 / 标准化 / 概率查表 / 反查分位点

适用专业与衔接 Suitable Majors

A-Level 数学是数学、工程、物理、计算机科学、经济学、金融、统计、精算、数据科学、运筹学等专业的基础科目。多数英国理工科与经济类专业要求 A-Level 数学为必修。课程为大学微积分、线性代数、概率论等课程提供必要前置知识。

A-Level Mathematics is foundational for mathematics, engineering, physics, computer science, economics, finance, statistics, actuarial science, data science and operations research. Most UK STEM and economics programmes require A-Level Mathematics as mandatory. It provides essential prerequisite knowledge for university calculus, linear algebra and probability courses.
